JTech Forums Desktop 0.2.9 adds clearer image viewing and a guided in-app introduction.

What's new:
- Open a post image in a fullscreen viewer and close it with the on-screen X.
- Stale server drafts are verified and retried during cleanup, so a reply you already posted should not reappear as an old saved draft.
- A first-run walkthrough spotlights key controls. Replay it at any time from Help & tour in the sidebar or Settings.
- Hover over Like to see whether the action will like or remove your like.

Installers:
- Windows: `JTechForums-0.2.9.msi`
- macOS: `JTechForums-1.2.9.dmg` (the package version follows the macOS bundle versioning rule)
- Debian/Ubuntu x86_64: `jtechforums_0.2.9_amd64.deb`

Windows may display a publisher warning because the MSI is not code-signed. macOS may ask you to approve opening an app downloaded from the internet. This is a community-built client, not an official JTech Forums organization release.
