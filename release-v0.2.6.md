JTech Forums Desktop 0.2.6 adds precise text selection actions in conversations.

What's new:
- Select a passage in a topic or private-message conversation and choose **Quote reply** to open the native composer with a Discourse-attributed quote already inserted.
- Choose **Copy quote** to copy the selected passage as a complete forum quote, including its author, post, and topic attribution. The existing **Copy** action still copies only the selected words.
- The README now contains an animated, screenshot-free feature illustration directly in this repository.

Installers:
- Windows: `JTechForums-0.2.6.msi`
- macOS: `JTechForums-1.2.6.dmg` (the package version follows the macOS bundle versioning rule)
- Debian/Ubuntu x86_64: `jtechforums_0.2.6_amd64.deb`

Windows may display a publisher warning because the MSI is not code-signed. macOS may ask you to approve opening an app downloaded from the internet. This is a community-built client, not an official JTech Forums organization release.
