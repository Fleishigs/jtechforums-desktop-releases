First public multi-platform installer release of the native JTech Forums desktop app.

Downloads:
- Windows: `JTechForums-0.2.5.msi`
- macOS: `JTechForums-1.2.5.dmg` (the app bundle uses a 1.x package version required by macOS)
- Debian/Ubuntu x86_64: `jtechforums_0.2.5_amd64.deb`

What's new:
- Centered the first-run desktop-app credits and clarified the maker note.
- Closed and archived topics now show a clear status and hide reply/quote actions.
- Includes the refreshed topic feed, composer, sign-in, notifications, and desktop polish.

Windows may display a publisher warning because the MSI is not code-signed. macOS may ask you to approve opening an app downloaded from the internet. This is a community-built client, not an official JTech Forums organization release.
